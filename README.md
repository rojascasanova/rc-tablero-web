# Tablero RC · versión web

Misma app, en el navegador. Sirve para Android, iPhone, Mac y cualquier PC.

**Instalar como app:**
- **Android (Chrome):** abre la página → menú ⋮ → *Instalar aplicación*
- **Mac (Safari):** Archivo → *Agregar al Dock*
- **iPhone (Safari):** Compartir → *Agregar a pantalla de inicio*

Los datos son los mismos del escritorio (Supabase). Cada persona entra con su cuenta.
